# PSA Arbitrage Agent

An AI-powered trading card arbitrage platform.

The goal is to identify profitable PSA slab opportunities
between the US and Australian markets.

## Features

- Market price comparison
- Profit calculation
- ROI ranking
- Telegram notifications
- Claude AI analysis
- Historical tracking
